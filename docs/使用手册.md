# 烤豆 RoastCurve · 使用手册

## 一、核心概念：两种烘焙模式

| 模式 | SV 设定温度 | 说明 |
|---|---|---|
| **手动** | 你控制（±5 按钮） | 传统用法，随时手调火力 |
| **跟随曲线** | 自动（每 2 秒按模板覆盖） | 复刻目标曲线，温控器自己跟着跑 |

**关键认知**：跟随时 SV 是「只读」的，控制器持续覆盖它。
±5 按钮在跟随时只有一个作用——**一键接管**：按下瞬间退出跟随、切回手动。

---

## 二、连接与记录状态

| 状态 | 头部按钮 | 行为 |
|---|---|---|
| 未连接 | （无开始/停止） | 只能看设置和历史 |
| 已连接 · 待命 | 开始 | 实时豆温照常显示，但不画曲线不走计时 |
| 已连接 · 记录中 | 停止 | 曲线绘制、计时走动 |

- 开启（省事）：连上即开表
- 关闭（默认）：连上先待命，确认温度正常后点「开始」手动起表；投豆瞬间点「入豆」也会隐式起表

「停止」= 断开连接并把曲线定稿保存。「断开」按钮行为相同。

**信号强度提示**：连接成功后，顶部「已连接温控器」旁会显示彩色圆点 + 具体 dBm 值——绿=强、黄=中、橙=弱、红=极弱。烘焙前瞄一眼，若为橙/红说明桥接器离路由器太远或有金属遮挡，建议调整位置/天线，避免中途掉线。

## 三、完整烘焙流程

### 准备
1. 给温控器和 Wi-Fi 转 RS485 设备通电
2. 打开 App，等待自动连接（可在设置开关）或手动点「连接」
3. 若需预热：确认在记录状态，用 ±5 把 SV 设到预热温度

### 入豆（计时起点）
4. 投豆的瞬间，点「**入豆**」（绿色按钮）
   - 清空预热段数据、计时归零、记录入豆时刻豆温
   - 跟随模式的时钟锚定在这一刻
   - 若处于待命态，入豆会自动开始正式记录

### 选模板并跟随（可选）
5. 点「跟随曲线」→ 弹出模板列表 → 选一炉（仅选中不立刻跟随）
   - 入豆时若开着「入豆自动开始跟随」，自动进入跟随
   - 图表上米灰色虚线 = 目标曲线，橙色实线 = 实际豆温

### 烘焙过程
6. 点**事件标记**即可，全程不用碰 SV：
   - 「黄点」：豆子转黄、草味消退
   - 「一爆」：第一声爆裂起
   - 「一爆止」：爆裂声结束（深烘模式另有 二爆/二爆止）
7. 阶段卡自动算出脱水 / 美拉德 / 发展三段时长与占比
8. 一爆后标题行实时显示「发展 MM:SS · 发展率 XX%」

### 出豆与收尾
9. 点「**出豆**」（蓝色按钮）：
   - 自动把 SV 写到 25°C 进入冷却
   - 立即保存一版记录兜底
10. 冷却完成后点「停止」，最终定稿保存
11. 到「记录」→ 点开这条记录，可补录生豆重/熟豆重，自动算失重率

## 四、记录保存机制

| 时机 | 行为 |
|---|---|
| 连接期间 | 每 30 秒自动存草稿 |
| 点出豆 | 立即存一版快照 |
| 停止/断开 | 最终定稿 |

同一炉的所有保存都是同一条记录的覆盖更新。**App 崩溃或意外断连最多丢最近 30 秒数据**。

锁屏 / 切后台安全：烘焙会话期间有前台服务保活（通知栏显示「烘焙进行中」），进程不会被系统回收，曲线继续记录。建议同时在 i 管家里给 App 开「后台高耗电」白名单双保险。

## 五、创建烘焙模板

### 方式一：从历史记录提取
1. 「记录」→ 选一炉满意的记录 → 右上角「存为模板」
2. 该炉曲线（出豆处截断）即成为可回放模板

### 方式二：导入 Artisan 曲线
1. 监控页 →「跟随曲线」→「导入」→ 说明框确认后选择 Artisan 导出的 .alog 文件
2. 自动解析豆温曲线生成模板（文件名即模板名），入豆/出豆锚点自动带上
3. 若 .alog 自带 computed 事件（入豆/脱水/一爆/出豆的时间与温度），导入时直接读取为锚点；缺失时回退为温度阈值推导，其余中间节点可在编辑器补充标注

### 方式三：自定义锚点绘制
1. 监控页 →「跟随曲线」→「+ 新建自定义模板」
2. 上方预览图实时呈现目标曲线形态
3. 编辑锚点列表：每个锚点可命名（如 脱水/一爆）、改时间（秒）和温度
4. 预览图支持手势：点空白处加锚点、长按锚点拖动调位置；精确数值在下方列表修改
5. 保存后与其他模板同等使用

### 管理
选择器里每条自定义模板可「编辑」「删除」；历史提取的模板只能删除。

## 六、设置项说明

| 设置 | 默认 | 说明 |
|---|---|---|
| 入豆自动开始跟随 | 关 | 开着时：入豆瞬间若已选模板，自动进入跟随模式 |
| 启动时自动连接 | 关 | 打开 App 自动连上次的桥接器 IP |
| 深烘模式（显示二爆） | 关 | 事件条增加 二爆/二爆止 两键，意式深烘用 |

**事件条规则**：未开表时仅「入豆」可点（投豆即正式开表），其余事件置灰防误触。

## 七、事件术语速查

| 事件 | 含义 |
|---|---|
| 入豆 CHARGE | 生豆下锅，计时起点 |
| 黄点 DRY | 豆色转黄，脱水阶段结束 |
| 一爆 FCs | 第一声爆裂，发展期开始 |
| 一爆止 FCe | 一爆爆裂声结束 |
| 二爆 SCs | 第二爆开始（深烘区间） |
| 二爆止 SCe | 第二爆结束（深度烘焙极限区） |
| 出豆 DROP | 下豆，记录终点 |

## 八、阶段统计参考（Artisan 口径）

- **脱水**（入豆→黄点）：通常占全程 40~50%
- **美拉德**（黄点→一爆）：通常 25~40%
- **发展**（一爆→出豆）：滤杯常见 18~22%，深烘可更高
- **失重率**：（生豆重−熟豆重）÷生豆重×100%，典型 12%~18%，超出 8%~25% 区间会提示复查

---

## 九、注意事项与已知边界

1. **空载测试**：空锅跟随带豆模板，BT 会升得比模板快、偏高，属正常物理差异
2. **总线上单主站**：接自制桥接器时，原 Wi-Fi 转 RS485 设备需断电，两个主站不能同时说话
3. **SV 上限 260°C**：适配特殊豆种；超出会被硬限幅
4. **返回键**：浮层页面（记录/详情/设置/编辑器）按返回=关闭浮层；烘焙会话进行中返回键被屏蔽防误触退出
