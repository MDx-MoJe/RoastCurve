# 烤豆 RoastCurve · 快速上手

> 面向 Release 下载者：带你把「烤豆」从零跑起来——下载、接线、刷固件、配网、连接、第一炉。
> 本教程只讲操作，不深入原理。App 内使用细节见《[完整用户指导手册](完整用户指导手册.md)》。

## 0. 你会拿到什么

从下载页获取（GitHub 与 Gitee 同步发布）：

- GitHub：[Releases](https://github.com/MDx-MoJe/RoastCurve/releases)
- Gitee（国内快）：[发行版](https://gitee.com/MDx-MoJe/roast-curve/releases)

| 文件 | 用途 |
|---|---|
| `CoffeeBeanTracker-*.apk` / `roastcurve-*.apk` | Android 安装包，直接装手机 |
| `roastbridge-*.merged.bin` | **ESP32 桥接器固件**（合并镜像，含 bootloader + 分区表 + App） |

> `merged.bin` 是单文件合并镜像，刷写时偏移填 `0x0` 即可，不需要分开刷 bootloader / 分区表 / App。

## 1. 需要哪些硬件

| 硬件 | 说明 |
|---|---|
| Android 手机 | 7.0+，装烤豆 App |
| DIY 热风烘豆机 | 带温控器（台泉 TC4S 等，RS485 接口） |
| ESP32-S3 开发板 | 推荐 N16R8（16MB Flash + OPI PSRAM）款 |
| TTL 转 RS485 模块 | **自动收发款**（丝印 DI/RO 命名），约几块钱 |
| 杜邦线若干 | 母对母，5 根 |
| 24V 电源 | 给温控器供电（桥接器用 USB 供电即可） |

不需要电脑也能完成全部配置（刷写除外，刷写需要一台电脑或手机浏览器）。

## 2. 硬件接线（5 根线）

```
ESP32-S3 DevKitC-1          TTL转RS485模块（自动收发款）
┌──────────────┐            ┌──────────┐
│  GPIO17 (TX) ├────────────┤ DI       │
│  GPIO18 (RX) ├────────────┤ RO       │
│  3V3         ├────────────┤ VCC      │
│  GND         ├────────────┤ GND      │
└──────────────┘            └──┬───┬───┘
                               A   B
                               │   │
                          温控器 RS485 端子
```

**线序铁律（验证基线，勿改）**：

- 自动收发模块（DI/RO 命名）：**GPIO17(TX) → DI、GPIO18(RX) ← RO**
- 波特率固定 **1200**，接反会全线死寂（字节永远上不了总线）
- 若你的模块丝印是 **TXD/RXD 命名**：先确认视角（TXD 是模块输入还是输出），按「接设备视角」接线，接反是「读通写不通/全哑」的头号真凶
- RS485 的 A/B：**A 对 A、B 对 B**，极性照抄原设备接法；接反不烧但通不了

⚠️ **测试时给原 Wi-Fi 转 RS485 设备断电**。总线上两个主站同时说话会冲突。

## 3. 刷写固件（任选一种）

### 方式 A：网页刷写（推荐，零安装）

1. 浏览器打开 Espressif 官方网页刷写器：<https://espressif.github.io/esptool-js/>
2. 串口选择板子（USB 插上后出现的 COM 口），芯片选 **ESP32-S3**，波特率 115200
3. 偏移填 **`0x0`**，文件选下载的 `roastbridge-*.merged.bin`
4. 点 **Program** 刷入，完成后按板子 RST 键重启

### 方式 B：esptool 命令行

```bash
pip install esptool
esptool.py --chip esp32s3 --port /dev/cu.usbmodemXXXX write_flash 0x0 roastbridge-*.merged.bin
```

（Windows 端口形如 `COM3`，macOS 形如 `/dev/cu.usbmodemXXXX`）

### 方式 C：Arduino IDE 从源码编译（进阶）

改固件源码时才需要，见 [esp32-firmware/README.md](../esp32-firmware/README.md) 的「烧录步骤（Arduino IDE）」。

> **刷写没反应？** 按住板上 **BOOT 键**不放，直到传输开始再松手。

## 4. 配网（网页配网，推荐）

固件不内置 WiFi 密码，首次上电自动进配网模式；连不上 WiFi 时也会自动转配网模式（品红/紫灯闪）：

1. 板子进入配网模式（指示灯变化；WiFi 列表出现热点即代表就绪）
2. 手机 WiFi 列表里找到热点 **RoastBridge-Setup**，密码 **roast1234**，连上
3. 浏览器打开 **http://192.168.4.1**（或自动弹出配网页）
4. 填入你家 WiFi 的名字和密码，点「连接」
5. 板子保存凭据到 NVS（断电不丢），自动重启并连接 WiFi，状态灯变绿色

**蓝牙配网（备选，需 App）**：无凭据首次上电会先走 BLE，打开烤豆 App → 连接设置 → 「🔵 蓝牙配网」扫到 RoastBridge 后填 WiFi。BLE 超时未配会自动转 AP（上面步骤）。

## 5. 验证板子

1. 状态灯**绿色常亮** = WiFi 就绪
2. 浏览器打开 `http://<板子IP>:8898/status`，应返回 JSON（含 `rssi` 信号强度）
3. 或仓库根目录跑探测脚本：`python3 tools/probe_tc4s.py <板子IP>`

板子 IP 可在路由器后台找名为 `roastbridge` 的设备，或 App 连接时用 mDNS 自动发现。

## 5.5 首次使用 Web UI（浏览器控制台）

板子刷好固件并配网后，**不需要装 App**，浏览器就能烘焙。**iOS 用户推荐用这个**（iOS 版 App 开发中，浏览器是 iPhone/iPad 上唯一完整可用烤豆的方式）：

1. 手机 / 电脑连**同一个 WiFi**（板子所在网络）
2. 浏览器打开 `http://<板子IP>:8898`
3. 页面加载后：
   - 顶部实时显示豆温 PV / 设定 SV / 风机 / 信号强度
   - 点「**接管控制**」获得操作权（当前无人控制时才能接管）
   - 「**入豆**」开始记录，过程点黄点 / 一爆 / 出豆等事件按钮
   - 「跟随曲线」选模板或点「🖌 绘制曲线」手绘一条，点「启动跟随」自动烘焙
   - 曲线走完自动回落 25°C，记录自动保存在浏览器（刷新不丢）
   - 底部切「记录」页可看历史、导出 zip

**没连过 WiFi 第一次用**：板子上电自动进配网模式（手机 WiFi 列表出现热点 `RoastBridge-Setup`，密码 `roast1234`），连上后浏览器开 `http://192.168.4.1` 填 WiFi → 板子重启连网后，回到上面第 1-2 步。

> Web UI 与 App 是两套独立入口，同一时间只用一端启动跟随。

## 6. 安装 App 并连接

1. 手机安装 APK（首次安装需允许「未知来源」）
2. 打开烤豆，连接设置里填**桥接器 IP**（或开启自动发现）
3. 显示「**已连接温控器（实时）**」且 BT 有读数 = 全链路通，可以开烘了

**信号强度提示**：连接成功后顶部会显示彩色圆点 + dBm 值——绿=强、黄=中、橙=弱、红=极弱。若为橙/红，把桥接器挪近路由器或调整天线，避免烘焙中途掉线。

---

## 7. 第一炉烘焙（浓缩版）

1. 给温控器通电，打开 App 连接
2. 确认在记录状态，点「**开始**」
3. 投豆瞬间点「**入豆**」（计时起点）
4. （可选）点「跟随曲线」选一炉模板，自动烘焙
5. 过程点事件标记：黄点 → 一爆 → 一爆止 → 出豆
6. 「**出豆**」后自动保存，冷却完点「**停止**」定稿
7. 「记录」里可补录生豆/熟豆重，自动算失重率

详细流程（预热、跟随、阶段统计、模板制作、设置项）见《[完整用户指导手册](完整用户指导手册.md)》。

## 8. 与豆袋 App 互联（可选）

装姊妹应用 **CoffeeBeanTracker（豆袋）**，两 App 通过系统级接口互联：

- 烘完一炉，豆袋自动**扣生豆 + 熟豆入库**（幂等，重复推送不重复入账）
- 历史记录里可手动「补录到豆袋」；默认「只补熟豆」模式不需要先录生豆
- 豆袋需要 **3.0.14+** 才支持熟豆补录

## 9. 常见问题

| 现象 | 排查 |
|---|---|
| 连接后「读通写不通 / 全哑」 | **线序问题**。检查 GPIO17→DI、GPIO18→RO；TXD/RXD 丝印注意视角 |
| 连不上桥接器 | 手机和桥接器是否同一 WiFi？IP 填对没？板子状态灯是否绿色常亮？ |
| 信号弱（橙/红） | 桥接器离路由器太近/太远或金属遮挡，调整位置 |
| 想升级固件 | 同局域网可用 **OTA**：Arduino IDE 网络端口 `roastbridge` 上传，或 `tools/roast_ota.py` |
| 空锅跟随带豆模板 BT 偏高 | 正常物理差异，空载升温比带豆快 |
| 出豆后 SV 自动到 25°C | 正常，进入冷却 |
