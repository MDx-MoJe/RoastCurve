隐私政策

更新日期：2026-09-11　生效日期：2026-09-11　政策版本：2

欢迎使用烤豆（RoastCurve）。我们深知个人信息对您的重要性，本应用在设计上即遵循「数据不出设备」原则：所有烘焙数据仅保存在您自己的手机上，我们既不收集，也无法访问。

一、开发者信息

开发者：MDx

联系方式：geminimoje@outlook.com

本应用为独立开发者作品，通过开源仓库（GitHub / Gitee：MDx-MoJe）发布。如有任何隐私相关问题、数据删除请求或投诉，请通过上述邮箱联系，我们将在 15 个工作日内答复。

二、我们收集什么

本应用不收集、不上传、不分发您的任何个人信息。

  • 无需注册账号，没有登录，没有用户画像；
  • 没有广告 SDK，没有统计 SDK，没有崩溃上报 SDK；
  • 应用内所有代码与依赖均随安装包提供，不连接任何开发者服务器。

三、权限使用说明

本应用仅申请以下权限，且每项权限都只用于括号中说明的唯一目的。除此之外不申请通讯录、短信、相机、麦克风、日历、电话等任何权限。

网络访问（INTERNET / 网络状态）——用于连接您局域网内的温控桥接设备（Modbus TCP / WebSocket）。应用不访问任何互联网服务器。
WiFi 状态与多播（WiFi 状态 / 多播接收）——用于局域网内自动发现桥接器（mDNS）以及保持连接稳定。
蓝牙（附近的设备 / 蓝牙连接）——仅在您主动使用「蓝牙配网」功能时申请，用于把 WiFi 名称与密码发送给桥接器。使用前会先弹窗说明用途。已声明 neverForLocation（不用于推断位置）。
位置信息（仅 Android 11 及以下）——旧版安卓系统规定「扫描蓝牙设备」必须持有此权限，本应用因此仅在旧系统上请求，且仅用于发现桥接器。本应用从不读取、不存储、不上传任何位置数据，也没有任何定位功能。当该权限以「位置」名称出现在旧系统提示中时，它对应的实际用途是扫描蓝牙设备。
通知（POST_NOTIFICATIONS）——用于在烘焙进行中显示常驻提醒（进度与状态），可在系统设置中随时关闭。拒绝不影响烘焙功能。
前台服务与唤醒锁（FOREGROUND_SERVICE / WAKE_LOCK）——用于锁屏或切到后台时保持曲线采集不中断，避免烘焙记录丢失。
文件读写（系统文件选择器 / 媒体库）——仅在您主动导出或导入备份文件时访问。导出走系统媒体库写入「下载」目录；导入走系统文件选择器，由您选定文件。应用不申请任何存储权限。
豆袋互联权限——用于把烘焙记录发送给姐妹应用「豆袋」（CoffeeBeanTracker）扣减生豆库存。不涉及任何数据外传。

四、数据存储位置

您的所有烘焙记录、模板曲线与设置仅保存在本机应用私有目录中。卸载应用即彻底删除。我们没有任何服务器存放您的数据，因此也无法代表您删除——但您可以用「设置 → 数据备份」自行导出留存。

五、第三方组件与共享

本应用不集成任何第三方广告、统计或数据分析组件。我们不会向任何第三方出售、出租或以其他方式提供您的信息。若您主动点击应用内的 GitHub / Gitee / 爱发电链接，将跳转到系统浏览器，这些外部网站的数据处理适用其各自的隐私政策。

六、您的权利

由于我们不收集您的个人信息，通常不存在需要行使的查阅、更正或删除请求。若您认为我们持有您的信息，或对隐私处理有任何疑问，可通过第一节的邮箱联系我们，我们会如实核查并答复。

七、未成年人保护

本应用面向烘焙爱好者，不针对儿童设计，也不收集任何年龄信息或儿童个人信息。若监护人发现相关情况，可通过第一节邮箱联系我们。

八、政策更新

若未来应用引入任何涉及数据处理的新功能，我们将更新本政策，并在下次启动时通过应用内弹窗重新征求您的同意。历史版本政策可向第一节邮箱索取。
